# Ambient Gallery · 氛围图墙

主面板背后像挂在墙上的一串照片：每一张**大小不一、各自倾斜、彼此留白**，横向只落在面板中段。每张照片最多 **20 张图**轮播；**开箱就带着 5 张随包照片**（首次启动自动铺好），点一下即可换成**你自己的本地图片**；其中一张可以**隐蔽地播放本地视频**，一个快捷键就能让它安静下来、回到照片轮播。

所有图片与视频都只存在本机，不上传、不联网。

---

## 它做了什么

- **照片，不是格子**：默认 8 张照片，落位、尺寸、长宽比（4:3／3:2／5:4）与倾角都是确定性抖动的结果。它们靠拒绝采样彼此错开，**永不重叠**，也从不共享同一水平线——像一面照片墙上的装饰，而不是等分网格。
- **开箱有内容**：包里带着 5 张照片（`assets/photos/`），**首次启动**时复制进 `~/.dsh/ambient-gallery/media/` 并落成 8 个格子的帧，和用户自己挑的图走同一条路径。没有网络的机器上也是完整的墙——一张加载不出来的远程图不是留白，是墙上的洞。
- **不过大**：单张上限 21% × 26% 的面板尺寸，纵使只放 3 张也不会长成一块板子。
- **只占面板中段**：整面墙横向默认落在面板宽度的 **20%–80%** 之间（可在设置里各自调），左右两侧是阅读留白，边缘还有渐变淡出。
- **悬挂感**：每张照片上方有一根极淡的吊线（`--dsw-alias-label-tertiary` 渐变），并带一层柔和投影，强化「挂在墙上」的观感。
- **每张动态轮播**：一张照片里可以放最多 20 张图，按设定间隔交叉淡入（1.6s 过渡）。每张的首帧延迟带确定性相位偏移，所以整面墙是「涟漪式」亮起，而不是整齐地闪。
- **满 20 张之后**：再选图不会失败 —— 新图进、最旧的自动轮换出去（滚动窗口语义，两端都按 `.slice(-20)` 执行）。
- **没有图也能看**：某张照片空着时，用 canvas 现场生成 3 张不同母题（光池／条纹／弧线）的渐变图，同一位置每次刷新都一致（种子来自照片编号）。
- **点选本地图片**：进入「布置」模式后，点击任意一张照片即可多选本地图片，或直接把文件拖进去。
- **隐蔽视频照片**：其中一张照片可以是视频（默认第 6 张，可改位置或关闭）。它常态下与其他照片一样低浓度、静音循环；只有在布置模式下才会显示出播放控件。
- **一个键让它安静**：`Shift+V`（可重绑）暂停／恢复视频。**暂停时那张照片不是变黑或空掉——它退回自己的静图（没有的话用生成图），照常跟其它照片一起轮播**，所以整面墙永远是满的。再按一次，视频回来。
- **浓度可调**：0–100%，布置模式与设置页都能拉。
- **底层、不挡操作**：整面墙挂在 `shell.overlay` 上，根节点 `pointer-events:none`，每张照片低透明度 + `mix-blend-mode`，文字从上面流过依然清晰；它从不拦截点击、滚动或键盘输入（快捷键除外，那是它唯一主动监听的东西）。

## 装

```bash
dsh plugin --profile web add dsh-ambient-gallery
```

或从源码目录安装：设置 → 插件 → 安装本地包，指向本目录。

## 用

1. 右下角有一个很淡的圆钮（悬停才明显），点它进入**布置模式**。
2. 布置模式下：点任意照片选图（可多选）、拖文件进照片、调照片数量／左边界／右边界／浓度／间隔／模糊，以及**点「视频快捷键」再按下组合键**来改快捷键。
3. 点「完成」退出布置模式，图墙回到背景里。之后按 `Shift+V` 就能让视频安静下来／重新播放。

设置 → **氛围图墙** 里有同一组控件（还带说明），可以整体隐藏图墙、恢复默认、清空全部。

## 存储与接口

- 状态：`~/.dsh/ambient-gallery/state.json`（config + 每个位置的帧列表）
- 媒体：`~/.dsh/ambient-gallery/media/`（导入时重命名为随机 id，客户端文件名只作为展示信息保留）
- 首次启动（即 `state.json` 还不存在时）会把包里 `assets/photos/` 的 5 张照片铺成 8 个格子。**一旦 `state.json` 存在就不再 seed** —— 你清空过这面墙，插件就该记得，而不是每次开机都跟你商量一次。
- 路由（Host 半，仅本机 loopback 可访问）：
  - `GET/POST /plugins/dsh-ambient-gallery/state`
  - `POST /plugins/dsh-ambient-gallery/import`（原始文件体 + `X-File-Name`）
  - `GET/HEAD /plugins/dsh-ambient-gallery/media/<id>.<ext>`（支持 `Range`，视频可流式 seek）
  - `POST /plugins/dsh-ambient-gallery/remove?id=<id>`

图片走 HTTP 而不是 `localStorage`／data URL，是因为手机照片几张就会撞到 5MB 配额，而视频 base64 进内存既慢又会重复持有。

## 兼容性

`engines.dsh: ">=0.2.0-rc.2 <0.3.0-0"`，`engines.node: ">=18"`。四个 peer 依赖全部 optional。

## 已知取舍

- 图墙在 `shell.overlay` 里，而宿主的 overlay 层（`z-index:20`）恒在各列之上、且中心列自带不透明底色 —— 所以「画在内容下面」在实现上做不到，只能用**低浓度 + 混合模式**做出视觉底纹的效果，同时保证永不拦截事件。这是刻意选择，不是遗漏。
- 布置模式期间图墙会临时接管鼠标（否则无法点击选图），退出后立刻恢复穿透。
- `prefers-reduced-motion: reduce` 时图墙自动隐藏轮播与整面墙。
- 位置是**确定性**的（种子只由照片数量决定）：同一数量下每次刷新落位一致，换数量会得到另一面墙 —— 这样不会每次打开都在跳动。
- 快捷键是**全局按键监听**（宿主的 Client 没有 shortcut 服务），所以在输入框里打字也会命中它；这是刻意的取舍——一个「光标在输入框时就不灵」的快捷键等于不存在，而光标几乎总在输入框里。唯一让路的是快捷键录制器本身。
- 「视频已暂停」这个状态**刻意不持久化**：它是一次「先安静一下」的手势，如果存盘，下次开机会看到一面莫名其妙的静音墙。

## 开发

```bash
node --check lib/index.js
node --check lib/client.js
node tools/gallery-smoke.mjs lib/client.js   # 离线：加载器 / 槽位注册 / 渲染 / 布局断言
node tools/gallery-probe.mjs                 # 端到端：20 张上限、合并、clamp、快捷键、Range、视频
node tools/dump-places.mjs 5 8 12            # 导出 placements() 的真实几何到 tools/_places.json
python tools/preview-layout.py               # 把上面的几何画成 PNG 版式预览（几何预览，不是截图）
```

`gallery-smoke.mjs` 的 `--- layout ---` 段会断言：不重叠（按旋转后包围盒）、单张不超过 21% × 26%、尺寸/倾角/顶边都不均匀、总覆盖面积 < 40%、横向带为 20%/20%。

`assets/icon-180.png` 来自 `tools/make-icon.py`（Pillow），它从 `icon.svg` 的几何重绘同一套五窗格与播放三角，所以图标是「一份设计，两种格式」，不会各自漂移。`assets/photos/` 里的 5 张照片随包分发（长边 720、progressive JPEG），离线可用，不联网加载。

装入 profile 后，Host 改动需要 `plugin_manager set_plugin enabled=false → true` 重载。
